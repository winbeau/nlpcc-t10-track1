# 探索路线图 —— 冲破 s15=50.26(2×H200,~2 周到 6/20)

> 2026-06-04 收敛自长程讨论。**目标:一个在新论文上也稳的鲁棒系统**(Phase 2=隐藏的不同论文、占最终分 50%),而非贴 testp1 调。所有实验**挂 GATE-B 评测台离线验**,过了再烧 Codabench。

## 0. 现状 & 诊断(已坐实)
- 最优 **s15 union 50.26**;单模 s01 grid **47.80**;trivial≈19。
- **根因**:① 训练数据「≤1 少数类/段」伪先验(67% 段全-Sup,仅 8 段≥2)→ 召回天花板;② **真 OOD**(testp1 与 traindev **图片 0 重叠 = 完全不同论文**;段长 8.7 vs 5.3;**92% 图表 vs 50% 表**);③ 稀有类数据饥饿(140-540);④ **惯例约束**(gpt5 读图满分却只 25,卡在惯例非读图);⑤ PEM 召回受限 + 长段复利狠。
- **已死,别试**:堆 union 成员(规模/架构多样性全 ≤50.26,越大越差)、外部文本增强、抑制类后处理、置信门控 union(退化成 s15)、gpt5 零/few-shot 分类器(25)、提分辨率、过采样调召回、2-epoch、两阶段路由(≡union)、PEM-margin joint loss(高方差,joint 单模历史 ≤grid)。

## 1. 统一实验框架(铁律)
- **训**:只在 `data/devbench/train_sft.jsonl`(image-disjoint train',**从不见 dev'**)→ 无泄漏。
- **离线评**:`dev_gold_densematch.jsonl`(testp1-shaped,trivial≈17,Spearman+0.59=泄漏下界但唯一可信代理)。看 **PEM 不跌 + 召回↑ + 逐类分布逼近 gold**(Sup 85.7/SO 7.7/UE 2.9/Contra 2.1/UCM 1.6)。
- **交 Codabench**:只在 densematch 上**明显优于 s15-同台分**才交(省配额)。每发前 `validate_submission.py` + 顶回 s01 保底。
- **命名**:`testp1_s{NN}_{m|pp|u}_{desc}`,记 `submissions_log.md`。s01(47.80)/s15(50.26)永久保底。
- **资源**:2×H200。8B LoRA ~1-1.5 GPU-h/个 → 可快速轮转。soup/自洽/误差分析是 CPU/推理,不占训练卡。

## 2. 方向清单(按类,标注攻击哪个根因 / 成本 / 预期)

### A. 训练目标 & loss(反过拟合 + 校准;便宜)
- **A1 softmin ablation**〔根因④⑤〕:同 per-sentence 格式下 plain-CE vs softmin 对照。softmin 是旧(precision)框架+泄漏 dev 调的,**从没干净比过**。`≤grid 就扔掉 softmin`。成本:1 训练。
- **A2 校准 loss**〔根因③④〕:balanced-softmax / logit-adjusted loss(按类基率校准,**不靠过采样的过拟合**)→ 稀有类召回↑且不背样本。可能是最对症"稀有类记忆"的。成本:1 训练(改 loss)。
- **A3 SAM + label smoothing**〔根因(过拟合)+②〕:锐度感知最小化(平坦极小)+ 标签平滑(反过度自信)→ OOD 更稳。near drop-in。成本:1 训练(换优化器,~2× 步耗)。

### B. 数据构造(修先验 + 数据饥饿;本地纯 Python 起)
- **B1 密度匹配训练**〔根因①〕★主攻:**同图(sha)内**把多条真少数类句合成"长+密"段落(标签不坏)+ joint 训练 → 修「≤1/段」先验 → 单模在密集长段一次抓多个真少数类。成本:本地造数据(免费)+ 1 joint 训练。预期 +2~4(EV 最高但有"以召回换FP"风险,故必须 densematch 验 PEM)。
- **B2 LLM 合成少数类样本**〔根因③〕:用任务 label 定义+真 few-shot,生成 UCM/SO/UE(不碰 Contra,需视觉)的 5-类样本,**标签零错位、无外部域偏移**。成本:生成+质检+1 训练。预期 +0~1.5。

### C. 泛化 / 鲁棒(攻 OOD,直助 Phase-2;最便宜)
- **C1 Model soup / 权重平均**〔根因②〕★先做:平均**同基座同配方**的 8B per-sentence LoRA(s01/s08/s09…)权重成**一个**模型 → 平坦极小 → OOD↑,且各自 FP 相互抵消(可能比 union 的"叠FP"干净)。**零训练、零配额**,平均+推一遍即可。预期:产出比 s15 更鲁棒的单一系统(Phase-2 最终系统候选)。
- **C2 self-training / 伪标**〔根因②〕**降级/可选**:只在 Phase-2 放出后、对 Phase-2 无标签输入、只取超高共识+大量真数据锚定(防确认偏误)。默认不做(贴目标拟合、不泛化到另一目标)。

### D. 读图接地(攻图表读取弱;先量化再决定)
- **D1 误差分析**〔诊断〕★先做(便宜、有 gold):比对 8B 的 dev 预测 vs gold,**按证据类型(image/table)分桶**——8B 的错是否集中在 image(图表)句?Contradiction/UE 这些"靠数字"的类是否图主导?**定"读图弱"占错误多少**,决定 D2 值不值。
- **D2 前沿读图 → 喂 8B**〔根因(读图)〕:gpt5/Claude 把图表数字转写成文本(claim-conditioned)作**附加通道**(原图始终在,转写错有兜底)→ 喂**懂惯例的微调 8B** → 结合"前沿读图 + 8B 惯例"(gpt5 单独失败在惯例,8B 失败在读图,互补)。**仅当 D1 显示读图是大头才做**。成本:转写缓存(API)+ 1 训练。
- **D3 表格 OCR→文本**〔次要〕:表 ≈ 文本,转 markdown 喂入(便宜),但表非瓶颈 → 低优。

### E. 推理期(便宜加法,可叠在最终系统上)
- **E1 自洽采样【纯加法】**〔根因①⑤〕:每成员 temp>0 多采样,全部当独立 union 成员(min-votes=1,**只增不删**,绝不退化成 s16)→ 补正确召回。需给 infer.py 加 `--temperature/--n`。成本:推理 ~0.3 GPU-h。
- **E2 推理期 logit adjustment**〔根因③〕:对每句 5 类 logit 减 τ·log(类频),稀有类更敢开(**召回方向**,与已证伪的抑制反向)。需重推存 5 类 logit。零重训。

## 3. 执行排期(2×H200,cheap→贵,带决策门)
**第 1 波(Day1-2,几乎零训练,先摘低垂果实)**
- C1 model soup(零训练)+ D1 误差分析(CPU)+ E1 自洽采样(0.3h)+ A1 softmin ablation(1 训练)。
- 决策:soup 比 s15 稳?误差分析说读图是不是大头?

**第 2 波(Day3-6,各 1 训练,2 卡并行轮转)**
- A2 校准 loss、A3 SAM+平滑、B1 密度匹配 —— 三个训练在 2 卡上排队。
- 每个 densematch 离线评 → 只留 PEM 不跌且召回↑ 的。

**第 3 波(Day6-9,看前两波)**
- D2(若 D1 显示读图是大头)、B2 合成数据(若召回仍缺)、E2 logit-adjust。
- 把最优的几个**正交**改进合并(如 密度匹配模型 + 校准 loss + soup + 自洽)。

**Phase-2(6/11 放出 → 6/20)**
- 用前面选出的**最鲁棒系统**(很可能 = soup 或 密度匹配模型 ± 自洽)跑 Phase-2 隐藏集 + 交。
- 同步把 Phase-1 最优(≥s15 才换)定稿。**勿过拟合 Phase-1。**

## 4. 诚实的 EV 与心态
- **大概率落 50-52**(全程实验都在这吸引子附近);真突破到 53+ 需要"召回↑且不伤 PEM/惯例"同时成立,概率有但不高。
- **最高价值其实是"鲁棒性"**:Phase-2 占 50% 且是不同论文,一个泛化好的系统(soup/SAM/校准/密度匹配)即使 Phase-1 只 ~50,也能在 Phase-2 守住 → 最终分稳。
- **所有实验离线先验、不盲烧**;s01/s15 永久保底。

## 5. 一句话
**便宜先行(soup + 误差分析 + 自洽 + softmin ablation)→ 训练类轮转(校准loss / SAM / 密度匹配)→ 据误差分析定要不要前沿读图通道 → 合并正交增益 → 选最鲁棒系统备战 Phase-2。全程 densematch 台离线裁判,s15 保底。**
